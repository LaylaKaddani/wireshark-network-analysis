# wireshark-network-analysis

# Wireshark Network Analysis

## Overview

This repository presents practical network traffic analyses performed using **Wireshark**. The project focuses on capturing, filtering, and analyzing packets to better understand communications between hosts on a local network and across remote networks.

The analyses include the observation of **ARP**, **ICMP**, and **DNS** traffic generated during different networking scenarios.

---

## Objectives

The main objectives of this project are to:

* Capture network traffic using Wireshark.
* Analyze ARP communications on a local network.
* Observe ICMP packets generated by the `ping` command.
* Understand how DNS resolves domain names before remote communications.
* Compare local and remote network communications.
* Develop packet analysis skills used in networking and cybersecurity.

# ARP Traffic Analysis

This analysis focuses on the **Address Resolution Protocol (ARP)** and how devices discover the MAC address associated with an IPv4 address on a local network.

The following tasks were performed:

* Identified the active network interface using `ipconfig /all`.
* Identified the local IPv4 and MAC addresses.
* Captured ARP traffic with Wireshark.
* Applied the `arp` display filter.
* Generated traffic using the `ping` command.
* Examined ARP Request and ARP Reply frames.
* Observed the ARP cache using `arp -a`.

# Network Traffic Analysis

This analysis examines network communications generated with the **ping** command and compares communications between local and remote hosts.

The capture includes the observation of:

* ICMP Echo Request and Echo Reply packets.
* ARP resolution during local communications.
* DNS queries used to resolve remote host names.
* Differences between local and remote communications.

## Main observations

### Local communication

* ICMP packets are exchanged directly between hosts on the same network.
* ARP is used to resolve the destination MAC address before communication.

### Remote communication

* DNS resolves the destination hostname into an IPv4 address.
* Traffic is forwarded through the default gateway.
* Wireshark shows the local MAC address and the gateway MAC address rather than the remote host's MAC address.

## Protocols Observed

| Protocol | Description                                                      |
| -------- | ---------------------------------------------------------------- |
| ARP      | Resolves IPv4 addresses into MAC addresses on the local network. |
| ICMP     | Verifies connectivity between hosts.                             |
| DNS      | Resolves domain names into IPv4 addresses.                       |
| IPv4     | Provides logical addressing for network communication.           |
